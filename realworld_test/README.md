# Real-World Evaluation Test Folder

Place test images here to evaluate the trained CNN V4 model on real-world conditions.

### Naming Convention:
`<Letter>_<Background>_<Signer>_<Index>.jpg`

Examples:
- `A_plain_ravi.jpg`
- `B_cluttered_priya.jpg`
- `C_office_alex.png`

Alternatively, organize images into subfolders: `A/`, `B/`, etc.
